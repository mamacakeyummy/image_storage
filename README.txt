IMAGE MANAGER
1. Upload index.html ke repository add_image.
2. Aktifkan GitHub Pages pada main /root.
3. Buka website Pages.
4. Settings -> isi username, repo, branch, dan Fine-grained Personal Access Token.
5. Token sebaiknya dibatasi hanya ke repository add_image dengan permission Contents: Read and write.
6. Upload gambar -> klik gambar -> Copy Direct Image URL / HTML / Markdown.

Catatan keamanan: token disimpan di localStorage browser. Jangan pernah menaruh token di source code atau commit ke GitHub.
